      Mark Separation CNN

      connecting local test
      Waiting for the tracker server…

      A 10-layer CNN takes a crop around an enclosure or line mark and returns the writing alone, as an image, and which kinds of mark are in the crop: underline, strikethrough, oval, rectangle, a yes or no each. Every crop is scaled to fit 600 × 100 and padded with white. It trains on one GPU; validation and the one-time test use the val and test crops, which have both enclosures and line marks. Florence Tuning's recognition needs a mark separator to take marks out of each detected line: this run's model, copied back when training ends, or one saved in note_synth/inference/mark_separation/, which lets Florence Tuning start without training here first.

          Save to inference

          Copies a checkpoint of this run into note_synth/inference/comprehension/ as a new model, with its validation scores. The explorer can run it, a new run can train further from it, and the Models tab compares it with the others. A name that's taken is refused, so a saved model is never overwritten.

          Restart training?

          Save the weights you want to keep to inference/ first. This run's checkpoints are deleted from the GPU VM when the next run starts, except the one it continues from.
          The next run

          Continuing trains the checkpoint's weights further with a fresh optimizer and learning-rate schedule, at its LoRA rank. You set epochs, budget and the rest at Start, on the dataset as it is then. The charts, samples and logs move to runs/archive/ and this page starts empty, with cost counted from $0.

          Restart training?

          The next Start trains the CNN from freshly initialised weights, on the crops as they are when you press Start. It becomes available once the synthesis run has finished.

          This run's checkpoints are deleted from the GPU VM when the next run uploads its code, together with its data copy and test marker. The VM and its Python environment are kept. The charts, samples and logs move to runs/archive/ and this page starts empty, with cost counted from $0.

          Save to inference

          Copies a checkpoint of this run into note_synth/inference/mark_separation/ as a new mark separator, with its validation scores. Florence Tuning can then start with it without this run training again, and Explore can take marks out with it. A name that's taken is refused, so a saved model is never overwritten.

          Sample run

          Generates 900 train and 100 val pages with the generator as it is now, into a folder of their own on the dataset VM, then counts the objects per page and pauses the VM. The dataset itself is not touched.

          Resumes the dataset VM with 16 vCPUs at $0.41/h, and stops at a $1.00 budget. Twenty train and twenty val pages are copied here to look at.

          Regenerate the whole dataset?

          Generates 30,000 train, 2,000 val and 2,000 test pages with the generator as it is now. The current dataset is deleted first, once the split caches are ready, since the disk can't hold two; if the run stops or fails after that, there is no dataset until a run finishes.

          The Florence Tuning GPU VM keeps its own copy of the old dataset. Resumes the dataset VM with 32 vCPUs at $0.81/h (one generator worker per vCPU; if 32 can't be had, its last size, 16 or 8, retried for up to 45 minutes), and stops at a $4.00 budget.
